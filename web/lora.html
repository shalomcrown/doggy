LoRa setup

Waveshare USB-TO-LoRa-xF: set the USB serial device (Linux /dev/ttyUSB0, Windows COM3) and host baud (module default 115200; USB-CDC often ignores baud). Choose HF (850–930 MHz) or LF (410–490 MHz). TXCH and RXCH are 0–80. AT uses TXCH/RXCH, not BAND/REGION. Dog and rover pages on this host proxy /api/* over LoRa (AES-256-GCM). /api/lora stays local.
